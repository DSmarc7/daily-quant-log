# daily-quant-log

Personal daily log combining three things:

- **`leetcode/`** — 1 algo per day, with solution + notes (approach, complexity, pitfalls)
- **`til/`** — Today I Learned: 1 short note per day on a quant / math / code topic
- **`market-tracker/`** — automated daily snapshot of indices, crypto, FX (via GitHub Actions)

## Latest market snapshot
See [`LATEST.md`](./LATEST.md) (auto-generated each day).

## Setup
See [`SETUP.md`](./SETUP.md) for everything: pushing to GitHub, configuring the daily Action, and installing the LeetHub browser extension to auto-push LeetCode submissions.

## Why this repo
Building a habit log + a portfolio asset at the same time. The market data accumulates into a real dataset usable for backtesting later, and the LeetCode + TIL entries become a personal reference I can search.
