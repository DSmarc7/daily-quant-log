# til — Today I Learned

One short note per day on something I learned. Targeted at quant / proba / stats / trading / numerical methods — but anything goes if it's interesting.

## Rules I set for myself
- Maximum 200 words per entry. If it doesn't fit, it's a blog post, not a TIL.
- Always include the **why I care** — context turns it from a fact into a memory.
- Equations welcome (LaTeX in markdown renders on GitHub).

## Structure
```
til/YYYY/MM/YYYY-MM-DD-short-slug.md
```

## How to add one
```bash
cp til/_template.md til/2026/05/2026-05-06-my-topic.md
# write it
git add til/ && git commit -m "til: my-topic" && git push
```
